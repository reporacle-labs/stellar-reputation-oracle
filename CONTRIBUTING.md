# Contributing to Stellar Reputation Oracle

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/<your-username>/stellar-reputation-oracle.git`
3. Install dependencies: `cd contracts/reputation && cargo build`
4. Run tests: `cargo test`

## Guidelines

- Keep PRs small and focused
- Add tests for new contract functions
- Follow existing code style
- Update documentation for new features

## Issues

Check open issues for tasks. Feel free to open new issues for bugs or feature requests.
